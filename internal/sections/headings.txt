# The phrases in headings that say which section a heading starts.
#
# Synonym rules, in the format Elasticsearch and Solr use: each rule is the
# section first, then the phrases that mean it, and a line ending with a
# comma carries on onto the next. A phrase is found anywhere in a heading,
# as whole words, in any case, and in the plural as well as as written
# ("duty" finds "Main Duties"). Write phrases as headings' keys are, in
# lower case with typographic quotes made plain: "what you'll be doing".
#
# Where a heading has phrases of more than one section, the section whose
# rule comes first here wins, so the order of the rules matters: "Desirable
# skills" is desirable, not requirements, and "What our client offers" is
# benefits, not company.
#
# A heading with none of these phrases is a details heading if it's a
# field's label ("Working Hours", followed by a list), as internal/headings
# knows them, and otherwise starts an unmapped section: the headings to
# find phrases for.
